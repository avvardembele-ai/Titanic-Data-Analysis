
# Titanic Dataset Analysis

## Project Overview
This project focuses on exploring and preprocessing the Titanic dataset using Python.

The goal is to understand the data, identify missing values, visualize important patterns, and prepare the dataset for further machine learning tasks.

## Technologies & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Contents
- `j1.ipynb` – Jupyter Notebook containing data analysis and preprocessing.
- `titanic.csv` – Original Titanic dataset.

## Key Activities
- Data exploration and analysis
- Handling missing values
- Data visualization
- Feature engineering
- Data preprocessing
- Creating new features such as `FamilySize` and `IsAlone`

## About
This is an educational data analysis project developed as part of my learning journey in Python and Machine Learning.
